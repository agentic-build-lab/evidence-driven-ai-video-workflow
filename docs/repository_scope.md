# Repository Scope

This repository contains the reusable parts of an evidence-led video production workflow.

Included:

- the lightweight Remotion director and example compositions;
- web capture, PDF bounding-box, privacy masking, and timing scripts;
- small official-source examples and quality-control artifacts; and
- configuration schemas and reproducible workflow documentation.

Excluded:

- dependencies and browser binaries;
- cookies, sessions, credentials, and local machine paths;
- large final renders and temporary downloads;
- third-party footage without clear redistribution rights; and
- licensed avatar assets that are not approved for public redistribution.

Local-only material belongs under ignored `work/`, `outputs/`, or `public/local_assets/` directories.
