# Source Materials Inventory

本仓库由旧实验项目 的证据型视频工作流整理而来。

## Included

- 旧项目核心方法文档已经提炼进 `docs/`。
- Remotion 可运行轻量 demo 在 `apps/remotion_director/`。
- 旧 V3/V4/V5 Remotion 源码保存在 `apps/remotion_director/src/legacy/`，用于参考。
- CNNIC PDF、官方截图、bbox JSON、同步事件表和抽帧检查图保存在 `examples/`。
- 网页采集、PDF bbox、隐私打码、公开视频探测脚本保存在 `scripts/`。

## Not Included In Git History

- `node_modules/`
- Playwright 浏览器二进制
- cookies 和登录态
- 大视频成片
- 版权不明确的公开视频原片
- 大型数字人视频素材

这些文件保留在本地 `work/` 或 `public/local_assets/` 时不会被提交。
