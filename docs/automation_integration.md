# Automation Integration

The workflow exposes a small set of stable automation boundaries:

- source capture from public web pages and PDFs;
- line-level text bounding boxes from DOM, PDF, or OCR data;
- privacy masking for faces and sensitive interface regions;
- narration-to-visual cue synchronization;
- deterministic Remotion rendering; and
- contact sheets, asset manifests, and release checks.

Automation must not bypass access controls, retain login state, or publish restricted media. Every public render requires a human review of source attribution, privacy masking, timing, and media rights.
