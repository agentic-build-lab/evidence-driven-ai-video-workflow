# Reference Video Usage

公开视频引用只用于必要片段和评论、说明、演示，不默认授权公开发布。

## Rules

- 不把公开视频原片提交到普通 Git 历史。
- 每个片段必须记录来源、用途、时长、是否打码、授权状态。
- 只截取必要片段，不做无关 B-roll 填充。
- 公开发布前复查平台条款和素材授权。
- 如需复现，优先放入 `work/`、Git LFS、GitHub Release 或私有素材库。

## Digital Human Assets

数字人素材如果是公开生成资产且只允许非商用使用，可以用于内部样片和本地渲染。公开仓库中默认只保留清单和使用说明，不把大文件直接提交到 Git 历史。
